# SysHome 🏠

Ласкаво просимо до **SysHome** — відкритого проєкту з автоматизації розумного дому на базі **Home Assistant**. 

Цей репозиторій містить мої налаштування, YAML-конфігурації та інструкції, які допомагають створити стабільну, швидку та повністю приватну систему автоматизації без хмарних сервісів.

## Про проєкт
SysHome народився з бажання зробити дім по-справжньому "розумним" та незалежним від зовнішніх серверів. Ми фокусуємося на локальному управлінні, стабільності та естетиці коду.

## Основні технології
* **Core:** Home Assistant
* **Protocol:** Zigbee (через Zigbee2MQTT)
* **Hardware:** [Тут можна вписати ваш сервер, наприклад: Raspberry Pi 4 / Intel NUC]
* **Logic:** YAML-автоматизації, ESPHome

## Що всередині?
- `automations/` — зібрані та протестовані сценарії автоматизації.
- `docs/` — інструкції з налаштування мережі та датчиків.
- `scripts/` — корисні скрипти для оптимізації системи.

## Початок роботи
Цей проєкт призначений для тих, хто вже знайомий з базовими налаштуваннями Home Assistant. Якщо ви новачок — почніть з вивчення офіційної документації [Home Assistant](https://www.home-assistant.io/).
